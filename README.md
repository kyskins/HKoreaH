# HKoreaH — запуск прототипа

Это автономный веб-прототип без установки зависимостей.

## Открыть напрямую

Откройте `index.html` в браузере.

## Запустить локальный сервер

Из корня проекта выполните:

```sh
python3 -m http.server 8000 --directory outputs
```

Затем откройте <http://localhost:8000>.

Фильтры вакансий, поиск по базе знаний, фильтры по гражданству / теме / типу материала, мобильное меню, FAQ и форма обращения работают на стороне браузера. Форма только подготавливает текст обращения для Telegram; данные на сервер не отправляются. Карточки вакансий демонстрационные. Для реальных аккаунтов, кабинетов, публикации вакансий и защищённого хранения документов потребуется серверная часть.

## База знаний

Встроено 20 карточек с кратким описанием первоисточника и ссылкой на официальный сайт. Есть отдельные источники по России, Казахстану, Кыргызстану, Узбекистану и Таджикистану, общий официальный маршрут EPS для участвующих стран и базовые ресурсы для других гражданств. Добавлены типы «текст», «PDF», «аудио», «видео» и «иллюстрированный гид». Первичные источники перечислены в `sources.md`.

Сведения о процедуре Казахстана помечены как находящиеся в запуске: включение в EPS объявлено 14 августа 2026 года, а дата фактического запуска отбора должна подтверждаться отдельными объявлениями. По квотам и приёму на 2027 год опубликованного подтверждения при проверке не найдено. Информация проверена 1 октября 2026 года.
